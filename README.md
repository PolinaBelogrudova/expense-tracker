BUSINESS EXPENSE TRACKER
Учебный проект по дисциплине "Проектирование и разработка бизнес-ориентированного ПО"
Автор: Белогрудова Полина Яновна

ОПИСАНИЕ:
Кроссплатформенное приложение для учёта бизнес-расходов и доходов на Python + Kivy.

РЕАЛИЗОВАННЫЕ ФУНКЦИИ:
1. Добавление расходов и доходов
2. Аналитика по категориям
3. Экспорт данных в CSV
4. Графики визуализации
5. Синхронизация с облаком (модуль под Firebase REST API)
6. Расчёт баланса в реальном времени

ДЛЯ ЗАПУСКА ТРЕБУЕТСЯ:
- Python 3.11
- Установленные библиотеки (см. ниже)

БИБЛИОТЕКИ:
pip install Kivy==2.3.0
pip install matplotlib==3.7.2
pip install numpy==1.26.4
pip install kivy-garden.matplotlib
pip install six

ЗАПУСК ПРИЛОЖЕНИЯ:
python src/main.py

СТРУКТУРА ПРОЕКТА:
- src/main.py — основной код приложения
- expenses.json — локальное хранилище данных
- expenses_export.csv — файл экспорта
- screenshots/ — скриншоты интерфейса

ПОТОК ДАННЫХ:
1. Пользователь нажимает "Добавить"
2. AddExpensePopup собирает данные (тип, категория, описание, сумма)
3. MainScreen.add_expense() сохраняет в JsonStore
4. JsonStore записывает в expenses.json
5. load_expenses() перечитывает данные и обновляет UI
6. ExpensesRV отображает список, баланс пересчитывается автоматически
